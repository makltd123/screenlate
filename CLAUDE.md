# ScreenLate

Офлайн-переводчик экрана для Android (en→ru). Полное ТЗ: [docs/SPEC.md](docs/SPEC.md). Перед любой работой перечитай нужные разделы ТЗ.

## Правила (выжимка из раздела 11 ТЗ)

- Работать строго по этапам из раздела 8 ТЗ. Перед этапом показать план и дождаться «ок». Не забегать вперёд.
- После каждого этапа: коммит, push, убедиться, что `build.yml` прошёл зелёным, и коротко по-русски написать, что проверить на телефоне.
- Не менять стек (раздел 3) и не добавлять сетевые запросы без согласования с владельцем.
- Если что-то не получается за 2–3 попытки (особенно ONNX-экспорт и SentencePiece), остановиться и описать проблему и варианты. Не обходить требования молча.
- Версии библиотек не выдумывать: перед добавлением зависимости проверить актуальную стабильную версию.
- Код и комментарии в коде на английском. Интерфейс, README.ru.md и чек-листы на русском.
- Владелец не Android-разработчик, у него нет IDE и эмулятора. Инструкции для него пошаговые, с телефона или через сайт GitHub.
- Текст с экрана не логировать нигде, кроме debug-сборки.

## Сборка

- APK собирается только в GitHub Actions (`.github/workflows/build.yml`). Локально нет Android SDK и JDK 17, поэтому `./gradlew` на этой машине не запускается.
- Юнит-тесты: `./gradlew testDebugUnitTest`. AGP 9 по умолчанию создаёт юнит-тесты только для debug.
- Подпись release: секреты `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`. Без них используется debug-ключ.

## Согласованные отступления от ТЗ

- `compileSdk = 37`, `targetSdk = 34`, `minSdk = 26` (согласовано 2026-10-22): Compose 1.12+ и core 1.19+ требуют compileSdk 37. Поведение на телефоне определяет targetSdk, он остаётся 34.
- README по общему правилу владельца: `README.md` на английском и `README.ru.md` на русском.

## Заметки по сборке

- Модель: `convert-model.yml` → релиз `model-v1` (помечен не последним). URL, SHA-256 и размер в `gradle.properties`, оттуда в BuildConfig и в CI. Эталоны: `app/src/test/resources/reference/` и `app/src/main/assets/selftest.json` (копия `translation_reference.json`).
- Квантование: QInt8 per-tensor, без `accelerate` (с ним выходной слой остаётся fp32 и декодирование в 3 раза медленнее). QUInt8, per-channel и reduce_range проверены: хуже по качеству и скорости.
- Объединённый декодер: кэш энкодера берётся только с первого шага, в ветке с кэшем он возвращает заглушки. Фиктивный past на первом шаге длины 1, не 0.
- int8 на x86 без VNNI считается с насыщением и даёт другие токены в ~30% предложений. Эталон сделан на точном железе; ARM телефона тоже точный. JVM-тест точного совпадения пропускается на CI-машинах без VNNI.
- SentencePiece 0.2.2 собирается из релизного архива (подпапка `sentencepiece/`), abseil он качает сам по git. CI собирает `libspm_jni.so` и под Linux для JVM-тестов.
- `libonnxruntime.so` 33 МБ, поэтому `useLegacyPackaging = true` (сжатие в APK).

- AGP 9: Kotlin встроен, плагин `org.jetbrains.kotlin.android` не подключается. Версия Kotlin поднимается строкой `classpath` в корневом `build.gradle.kts`.
- AGP 9 убрал старый variant API (`applicationVariants`). APK переименовывается в workflow.
